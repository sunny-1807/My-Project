# MBU Data Science Lab

## 📌 Overview

MBU Data Science Lab is a web-based project developed using HTML to organize and present Data Science laboratory resources for students. It provides a structured interface for accessing lab experiments, practical learning materials, and related academic content.

## 🎯 Objectives

- Provide an organized platform for Data Science lab experiments.
- Present practical learning resources in a simple HTML interface.
- Improve accessibility to laboratory materials.
- Organize experiment details for easy reference.
- Support students in their practical learning activities.

## 🛠️ Technologies Used

- **HTML5** – Web page structure and content
- **CSS3** – Styling and layout, if included
- **JavaScript** – Interactive functionality, if included

## 📂 Project Structure

```text
mbu-data-science-lab/
├── lab/       # HTML files and lab resources
└── README.md  # Project documentation
```

## ▶️ How to Run

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd mbu-data-science-lab
   ```

3. Open the `lab` folder.

4. Open the main HTML file in your web browser.
